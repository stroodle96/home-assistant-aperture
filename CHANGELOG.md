# Changelog

## 0.1.0

Initial community release for Home Assistant 2026.11 and Aperture.

- Independently configured gateway, model subentries and MCP connection.
- Assist conversation agents with streaming replies and selected AI tools.
- Text, JSON schema output and image-input AI tasks.
- Chat Completions, Responses and Anthropic Messages adapters.
- Paginated MCP discovery, preserved tool annotations and safe provider names.
- No automatic generation/tool replay; tool execution waits for a successful complete stream.
- Reauthentication, redacted diagnostics, catalog polling and unload/reload support.
- HTTP fixture tests and real Home Assistant container verification.
